# Briefing: Última órbita

## 1. Problema y Propósito
Desarrollar un videojuego arcade espacial 2D que busca ofrecer una experiencia de entretenimiento rápida y accesible basada en mecánicas clásicas de esquivar y disparar.

## 2. Usuario Objetivo
Jugadores casuales o estudiantes que busquen una experiencia de entretenimiento rápida, directa y accesible directamente desde un entorno local o web.

## 3. Objetivo del MVP
Una versión básica jugable que incluya:
* Una nave controlable por el usuario.
* Sistema de disparos hacia la parte superior.
* Generación de enemigos que descienden en oleadas simples.
*  Sistema de colisiones y detección de impactos.
* Marcador de puntuación y gestión de vidas con pantalla de fin de partida (*Game Over*).

## 4. Decisiones Tecnológicas / Preguntas Abiertas
* **Tecnología base definida:** El juego se implementará en JavaScript para navegador, usando HTML5 Canvas. No se utilizará Python/Pygame.
* **Balanceo de dificultad:** Decidir la tasa de aparición de enemigos y velocidad inicial de la nave tras las primeras pruebas del MVP.
